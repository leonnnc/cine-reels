Puente con Facebook (opcional)

El oEmbed de Meta exige un access_token de aplicación y no debe ir en el navegador. Arranca el servidor incluido (node server/serve.mjs) y aquí solo configuras la ruta del proxy. Sin proxy, el sistema funciona igual: pegas el enlace y los datos a mano.

Qué se puede y qué no

  • Sí: incrustar reels públicos con el plugin oficial y leer sus datos con oEmbed.
  • Sí: buscar dentro de tu propio catálogo con puntuación y filtros.
  • No: buscar reels de terceros por palabra clave; la Graph API no expone un buscador de reels.
  • No: raspar HTML de Facebook: rompe sus términos y el código deja de funcionar a las semanas.
